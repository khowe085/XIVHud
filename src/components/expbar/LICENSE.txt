Third-party notices for the expbar component.

This file collects the upstream notices the source transcribed into this
component's Lua depends on (BSD clause 1 also keeps each such notice in the
derived source file itself). The bar art the component draws is not here: it
sits under src/assets/barfiller/ with its own notice, as every other bundled
image does.

Source transcribed into this component's Lua
--------------------------------------------------------------------------------

    logic.lua        the point-tracking approach, from the PointWatch addon,
                     BSD (c) 2014 Byrthnoth: which packets carry experience,
                     exemplar points, limit points and merits (0x061 and
                     0x063 order 2), the action-message ids that carry each
                     gain, the rate registry (a ten-minute window
                     extrapolated to the hour off its oldest sample), the
                     limit-point wrapping rule, and the exemplar message
                     pair 809/810, which no resource file vouches for
    logic.lua        the bar itself, from the BarFiller addon, BSD (c) 2015
                     Morath86: the 472x5 frame with its fill inset two
                     pixels, the exponential ease toward the target width,
                     and the experience-chain message (253) PointWatch has
                     no entry for

Neither addon's code is copied verbatim; both are re-implemented against this
framework's contracts, and the defects listed in .claude/Planning/expbar.md
are deliberately not reproduced.
