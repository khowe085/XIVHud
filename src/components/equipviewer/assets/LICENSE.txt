One image file in this directory (encumbrance.png) is taken from the
equipviewer addon:

    https://github.com/Windower/Lua/tree/dev/addons/equipviewer

The icon extraction this component performs - the DAT ranges, the record
layout, the palette rotation and the bitmap header in icons.lua - is a
re-implementation of that addon's icon_extractor library, whose base extraction
code its author credits to Trv.

equipviewer ships no separate asset licence, so its source licence is the basis
on which both are redistributed here. That notice is reproduced in full below.

The other image file (panel.png) is XIVHud's own: an 8x8 white square, tinted at
runtime to draw the panel behind the grid.
