Third-party notices for the invtracker component.

This file collects the upstream notice the source transcribed into this
component's Lua depends on (BSD clause 1 also keeps that notice in the derived
source file itself). No art is here, and none ships with the component: the
squares are drawn from src/assets/own/panel.png, XIVHud's own white square,
tinted at draw time. The reference addon's own slot.png is a 1x1 white pixel
serving the same purpose, and redistributing a second one would have added a
file without adding a texture.

Source transcribed into this component's Lua
--------------------------------------------------------------------------------

    logic.lua        the widget itself, from the invtracker addon, BSD (c)
                     2017 sylandro: a bag drawn as one square per slot on a
                     4px pitch with a 3px shadow under a 2px box, the blocks
                     laid side by side with a gap between them, the status
                     colours and their darker backgrounds, the display sort
                     (status, then the stack nearest full, then the count)
                     that the addon's README explains as standing in for a
                     sort order the client does not report, the packets that
                     say an item may have moved, and the treasury and
                     temporary bags drawing only what they hold

The code is not copied verbatim: it is re-implemented against this framework's
contracts, and the defects listed in .claude/Planning/invtracker.md are
deliberately not reproduced - among them the leaked prims on reload, the
unknown item status that drew an occupied slot as empty, and the wardrobes 5
to 8 the reference cannot see.
