What is in this directory, and where it came from
--------------------------------------------------------------------------------

Every image below is a verbatim, byte-for-byte copy of its source file - no
image was re-encoded, resized, or otherwise transformed. Paths on the right
are relative to the xivcrossbar repository root.

    spells/                              images/icons/spells/ (by recast id)
    abilities/                           images/icons/abilities/ (by recast
                                          id), plus the three named icons from
                                          images/icons/iconpacks/default/abilities/
    weapons/                             images/icons/weapons/ (the .png set
                                          the slot code resolves; the unused
                                          capitalised .jpg set is not shipped)
    elements/                            images/icons/elements/
    skillchain/                          images/icons/iconpacks/default/skillchain/
                                          (.png only; the .svg twins are not
                                          shipped)
    mounts/, trust/,                     images/icons/iconpacks/default/<same>/
      ninjutsu/, blue-magic/,
      items/, weaponskills/
    *.png (the top-level singles:        images/icons/iconpacks/default/
      attack, disengage, dismount,        (top-level)
      mount, item, map, and the rest)

the upstream addon redistributes them.
